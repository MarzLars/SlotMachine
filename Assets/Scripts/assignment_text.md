Designing a Slot Machine in Unity 6
Topic: Randomness in video games AI

Objective
In this assignment, you will explore the role of randomness in game design by creating a digital slot machine concept/prototype using Unity 6. The goal is to understand how randomness can be controlled and balanced to maintain player engagement while ensuring profitability for the game system. You are allowed to collaborate with other students, but your design document (see: Deliverables) must be unique.

Task description
You are to design and implement a 5x5 slot machine interface where:

The player starts with 10,000 credits.
The machine displays a 5x5 grid of symbols.
The player can interact with the grid using buttons for each row and column (10 buttons total).
Pressing a button will re-roll the symbols in that row or column.
Payout schemes
You must implement a minimum of five different payout schemes, such as:

Matching symbols in a row or column
Diagonal matches
Clusters of identical symbols
Special symbol combinations (e.g., wildcards or bonus icons)
Full grid patterns (e.g., all corners match)
Each scheme should have its own reward logic, but the overall system must be designed so that the machine always makes money over time. This involves:

Designing probability distributions for symbol appearances.
Implementing expected value calculations for each scheme.
Ensuring player retention through perceived fairness and excitement.
Technical requirements
Unity 6 project targeting Android devices or Windows PCs.
Responsive UI for interaction.
Visual feedback for wins and losses.
Credit system with updates after each interaction.
Basic sound effects and animations (optional but encouraged).
Deliverables
Unity project files (.zip, .unitypackage, or GitHub repo)
Please clean up and deliver only the necessary folders and files
Design document (PDF) in the Assets-folder, explaining:
Your approach to randomness
Description of payout schemes logics
How you ensured "profitability"
Any challenges and how you solved them
Short gameplay video (1–2 minutes) demonstrating the slot machine in action (url to video will do)
